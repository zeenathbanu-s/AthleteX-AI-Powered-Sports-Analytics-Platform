# AthleteX: AI-Powered Sports Analytics Platform

## Overview

AthleteX is an AI-powered sports analytics platform developed to revolutionize athlete performance evaluation and training. The platform leverages Artificial Intelligence, pose detection, and data analytics to provide real-time insights, helping athletes and coaches make informed decisions and improve training outcomes.

Developed as part of Smart India Hackathon (SIH) 2025, AthleteX aims to bridge the gap between sports and technology by enabling intelligent, data-driven athlete assessment and performance monitoring.

---

## Problem Statement

Traditional athlete evaluation methods are often manual, time-consuming, and lack real-time insights. Coaches face challenges in accurately monitoring athlete performance, identifying strengths and weaknesses, and providing personalized training recommendations.

There is a need for an intelligent platform that can:

- Analyze athlete performance efficiently.
- Provide real-time insights and analytics.
- Support coaches in monitoring athlete progress.
- Enable data-driven decision-making in sports.
- Improve training effectiveness using Artificial Intelligence.

## How It Works

1. Athletes register and access the AthleteX platform.
2. Performance-related data is collected and processed.
3. AI-powered modules analyze athlete movements and activities.
4. Pose detection technologies evaluate posture and performance.
5. Performance metrics are generated and displayed through interactive dashboards.
6. Coaches monitor athlete progress and provide training guidance.
7. Athletes receive actionable insights and recommendations to enhance their performance.

## Installation

### Clone the Repository

```bash
git clone https://github.com/zeenathbanu-s/AthleteX-AI-Powered-Sports-Analytics-Platform.git
```

### Navigate to the Project Directory

```bash
cd AthleteX-AI-Powered-Sports-Analytics-Platform
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm start
```

The application will run on:

```text
http://localhost:3000
```
